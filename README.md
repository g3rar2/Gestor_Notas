# Gestor de Notas

Aplicacion multiplataforma de notas creada con .NET MAUI. El proyecto usa SQLite para almacenamiento local y sigue una estructura MVVM.

## Tecnologias

- .NET 8
- .NET MAUI
- SQLite
- CommunityToolkit.Mvvm

## Como ejecutar

1. Abrir `GestorNotas1Q2025.sln` en Visual Studio.
2. Restaurar paquetes NuGet.
3. Seleccionar la plataforma objetivo.
4. Ejecutar en emulador o dispositivo.

## Nota para portafolio

El repositorio debe mantener solo codigo fuente y recursos necesarios. Las carpetas `bin/`, `obj/` y configuraciones locales del IDE no deben publicarse.
